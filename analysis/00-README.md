# Аудит и статус приложения Shift — оглавление

Комплексный анализ Android-клиента игры Shift, выполненный 2026-07-22, и живой статус проекта.
Фокус — **надёжность в бою** (игра ещё предстоит), безопасность — отдельным разделом,
красота кода намеренно вторична.

## С чего начать

👉 **[11-status.md](11-status.md)** — **актуальное состояние на сегодня**: снапшот проекта,
перепроверенный по коду список топ-проблем аудита (что реально починено, что нет), открытый
бэклог, закрытые направления и полевые заметки. Это единственный источник правды по текущему
состоянию.

Историю того, как проект дошёл до этого состояния, см. в [08-changes-applied.md](08-changes-applied.md).
Исходный вердикт аудита (снапшот 2026-07-22) — в [01-executive-summary.md](01-executive-summary.md).

## Система обозначений
- **Severity**: Critical → High → Medium → Low.
- **ID находок**: R# (reliability), T#/AU#/CH#/AR#/NO#/MA# (subsystems: Terminal/Aura/Chat/Artifact/Noise/Maps),
  S# (security), B# (build). На них ссылается executive summary.
- **P1/P2/P3** в [11-status.md](11-status.md) — приоритетные открытые дефекты на сегодня
  (не путать с P0/P1/P2 приоритетами плана из аудита).
- Ссылки на код — в формате `файл:строка`.

## Как это собиралось
- Прочитана вся кодовая база, `AndroidManifest`, gradle-конфиги, ресурсы.
- Проект собран (`assembleDebug`, успешно) на JDK 17.
- Живой прогон на эмуляторе `Pixel_6_API_35` (Android 15) под игроком `Bas` и мастером `MG_Bas`.
- Часть разбора выполнена параллельными саб-агентами; спорные severity перепроверены вручную.
- С 2026-07-23 проект дорабатывается сериями коротких автономных ночных сессий
  (см. `~/.claude/scheduled-tasks/nightly-shift-improver`), плюс ручные сессии владельца.

## Важные оговорки
- **Backend вне области** (`shift96.ru`, чат-сервер по IP) — оценивался только со стороны
  клиента. Исключение: серверные находки, замеченные попутно, собраны в
  [11-status.md](11-status.md) §F.
- Баг **R1** (карта на Android ≤ 12) починен, но так и **не проверен на реальном устройстве**
  с Android 11/12 — только по коду.
- Security-пункты (keystore, cleartext HTTP, debuggable/minify, sha256 обновления, логи тел)
  владелец сознательно оставил как есть: свой доверенный сервер и ~30 знакомых игроков.
