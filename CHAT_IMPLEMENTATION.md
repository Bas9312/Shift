# Реализация чата в приложении Shift

## Обзор

В приложение Shift добавлен полнофункциональный чат с МГ (мастером игры), который использует API сообщений согласно предоставленной спецификации.

## Реализованный функционал

### 1. Модели данных
- **Message.kt** - основная модель сообщения с поддержкой вложений и тегов
- **MessageAttachment.kt** - модель для вложений (изображения, видео)
- **CreateMessageRequest/Response** - модели для создания сообщений
- **GetMessagesRequest/Response** - модели для получения сообщений

### 2. API клиент
- **MessagesApi.kt** - Retrofit интерфейс для работы с API сообщений
- Поддержка всех методов API: создание, получение, пометка как прочитанное
- Поддержка multipart запросов для вложений
- Интеграция в RetrofitClient с отдельным базовым URL

### 3. Пользовательский интерфейс

#### Главная страница
- Добавлена кнопка "Чат с МГ" на главную страницу
- Кнопка доступна всем пользователям

#### Активность чата (MessagesChatActivity)
- Современный UI в стиле мессенджера
- Список сообщений с поддержкой прокрутки
- Панель ввода с кнопками для:
  - Выбора получателя
  - Выбора тегов
  - Прикрепления файлов
  - Отправки сообщения

#### Адаптер сообщений (MessagesAdapter)
- Отображение сообщений в виде пузырьков
- Разное оформление для отправленных и полученных сообщений
- Отображение времени, отправителя, статуса прочтения
- Поддержка тегов и вложений

### 4. Функциональность

#### Отправка сообщений
- Текстовые сообщения
- Прикрепление файлов (изображения, видео)
- Выбор получателя
- Выбор тегов для сообщения
- Валидация данных перед отправкой

#### Получение сообщений
- Загрузка истории сообщений
- Автоматическое обновление списка
- Пометка сообщений как прочитанных при клике

#### Система уведомлений
- **MessagesService** - фоновый сервис для проверки новых сообщений
- **MessagesReceiver** - BroadcastReceiver для обработки уведомлений
- Toast уведомления о новых сообщениях

### 5. Безопасность и разрешения
- Запрос разрешения на чтение файлов для вложений
- Валидация типов файлов (только изображения и видео)
- Ограничение размера файлов (10MB согласно API)

### 6. Обработка ошибок
- Обработка сетевых ошибок
- Пользовательские сообщения об ошибках
- Graceful fallback при недоступности API

## Интеграция с существующим кодом

- Добавлена кнопка в MainActivity
- Обновлен AndroidManifest.xml
- Интегрирован в существующую архитектуру приложения
- Использует существующие хелперы (UserPrefsHelper)

## API совместимость

Реализация полностью соответствует предоставленной спецификации API:
- Все эндпоинты реализованы
- Правильные заголовки авторизации (X-User-Id)
- Поддержка всех параметров запросов
- Обработка всех кодов ошибок

## Особенности реализации

1. **Асинхронность** - все сетевые операции выполняются в корутинах
2. **Кэширование** - сообщения сохраняются локально для быстрого отображения
3. **UX** - плавная анимация, автоскролл, индикаторы загрузки
4. **Масштабируемость** - легко добавить новые функции (групповые чаты, реакции и т.д.)

## Использование

1. Пользователь нажимает кнопку "Чат с МГ" на главной странице
2. Открывается активность чата с историей сообщений
3. Пользователь может:
   - Вводить текст сообщения
   - Выбирать получателя
   - Добавлять теги
   - Прикреплять файлы
   - Отправлять сообщения
4. Новые сообщения приходят автоматически через фоновый сервис
