# Фамильяры SHIFT

В каталоге лежит по одному файлу на каждого фамильяра с ID 01-22.

Карточки Осколков Зеркала 02, 03 и 04 намеренно одинаковы, кроме ID: это три персонажа с одной общей инструкцией.

Файл `00_Исполнение-способностей.md` предназначен для общего системного ядра. Он определяет значения поля `Исполнение`:

- `MG` - игрок применяет способность через чат с МГ;
- `PLAYER` - игрок применяет и отслеживает способность самостоятельно;
- `PASSIVE` - способность срабатывает по правилам автоматически.

Чат фамильяра не применяет способности ни в одном из режимов.
